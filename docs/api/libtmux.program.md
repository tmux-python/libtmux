# Owned programs

{meth}`~libtmux.Session.run_program` returns completion and rendered output
after removing its owned pane. {meth}`~libtmux.Session.start_program` returns
an interactive {class}`~libtmux.program.Program` instead. See
{doc}`/topics/pane_interaction` for runnable examples and lifetime limits.
